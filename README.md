# Outpost — NASA Space Apps Challenge

Two games where students run a lunar or Martian outpost and balance life support, radiation shielding, power and food. Real NASA data (DONKI space weather, Curiosity RAD, Moon Trek, BVAD) drives the gameplay.

| Game | Play | Folder |
|---|---|---|
| **Outpost 3D: Walk the Base** — 3D, hand-written WebGL | https://outpost-3d.vercel.app | [`outpost-3d/`](outpost-3d/) |
| **Outpost: Last Light** — 2D dashboard game | https://outpost-3d.vercel.app/last-light | [`last-light/`](last-light/) |

Each game is a single `index.html` with no installs: double-click it, or open the links above. Each folder has its own README with the NASA data table, controls, Demo Mode script and self-test results (`node selftest.js`).
